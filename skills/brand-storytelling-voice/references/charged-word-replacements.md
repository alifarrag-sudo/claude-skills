# Charged Word Replacements — Working Vocabulary

A working vocabulary of neutral strategy words and their charged alternatives. Use when editing and the language feels flat but you can't see why. The left column is the word to find and eliminate. The right column is not a template — it is a direction. The actual replacement should be specific to the context.

---

## The Banned List — Words That Have Lost All Meaning

These words appear in almost every strategy document and mean almost nothing. Every time you write one, ask: what do I actually mean?

| Banned Word | What You Probably Mean | Write Instead |
|---|---|---|
| Authentic | Real, honest, not performing | *Specific to context — name the actual quality*  |
| Innovative | New, first, different | *Say what's new and why it matters* |
| Meaningful | Emotionally resonant | *Name the emotion* |
| Impactful | Effective, memorable | *Say what changes and for whom* |
| Empowering | Giving permission, enabling | *Name what they can now do that they couldn't before* |
| Engaging | Interesting, attention-earning | *Say why someone would stop scrolling* |
| Holistic | Complete, joined-up | *Say what's connected to what* |
| Dynamic | Changing, active, energetic | *Name the change or the energy* |
| Leverage | Use | *Use "use"* |
| Synergy | Working together | *Say what combining produces* |
| Ecosystem | System, network, world | *Name the actual components* |
| Journey | Experience, process | *Use only if the metaphor is truly relevant* |
| Storytelling | Writing, communication, narrative | *Use only if you mean actual story structure* |
| Tribe | Community, audience, group | *Usually just use "people"* |
| Disruptive | Breaking a convention | *Name the convention being broken* |

## Weak Verbs → Charged Verbs

| Weak | Charged Alternatives |
|---|---|
| Is / Are | *Carries, holds, drives, refuses, earns, owns* |
| Has / Have | *Holds, carries, sits on, is built from* |
| Offers | *Gives, delivers, opens, unlocks* |
| Provides | *Hands over, builds, makes possible* |
| Supports | *Backs, stands behind, holds up* |
| Addresses | *Answers, confronts, solves, closes* |
| Leverages | *Uses, draws on, builds from* |
| Creates | *Builds, makes, produces — or be specific: earns, wins, unlocks* |
| Drives | *Pushes, pulls, moves, earns* (avoid if overused) |
| Connects | *Bridges, links, reaches, finds* |

## Vague Nouns → Specific Nouns

| Vague | Direction |
|---|---|
| Consumers / Users | *Name them. "A 28-year-old in Riyadh." "Fleet managers who have to justify their choice upstairs."* |
| Audience | *Name who. The more specific, the more persuasive.* |
| Market | *Say which market and what's happening in it right now.* |
| Category | *Name the category — and its specific failure mode.* |
| Space | *Almost always vague. What space, specifically?* |
| Landscape | *Say what the landscape looks like. Paint it.* |
| Touchpoints | *Name the actual channels and why each one matters.* |
| Content | *Say what kind of content and what it does for the person receiving it.* |
| Solution | *Name what the solution actually solves.* |
| Experience | *Describe what happens, moment by moment.* |

## Hedging Language → Committed Language

| Hedging | Committed |
|---|---|
| It could be argued that... | *The truth is...* |
| There is a sense in which... | *[Just say the thing]* |
| This suggests that... | *This means...* |
| We believe there may be an opportunity... | *Here's the opportunity.* |
| It is worth noting that... | *[Cut the preamble. Note the thing.]* |
| Arguably... | *[Cut it. Take the position without the qualifier.]* |
| In many ways... | *[Cut it. Say the ways.]* |
| To some extent... | *[Cut it. Say the extent.]* |
| Perhaps... | *[Cut it or commit to it.]* |
| We feel that... | *We believe... / The evidence says...* |

## Overused Strategic Phrases → Fresh Alternatives

| Overused | Fresh Direction |
|---|---|
| "Meeting consumers where they are" | *Say where they actually are and why that matters* |
| "Building brand love" | *Name the specific feeling you're trying to build* |
| "Cutting through the noise" | *Say what you're cutting through and with what* |
| "Starting a conversation" | *Say what the conversation is about and who starts it* |
| "Owning the moment" | *Name the moment and why this brand can own it* |
| "Telling our story" | *Say which story, why now, and for whom* |
| "Driving consideration" | *Say what makes someone consider this vs. not* |
| "Adding value" | *Name the value. What does the person now have that they didn't?* |
| "Best-in-class" | *Say what class and what makes it best* |
| "Thought leadership" | *Say what thought and why this brand is positioned to lead it* |

## A Note on Writing in Other Languages

The same principles apply in {{OUTPUT_LANGUAGE}} and in any other language you write strategy in. Every language has its own stock of overused strategic phrases that carry the same flatness as their English equivalents. Build a short watch-list for each language you work in.

Worked example, Arabic: Modern Standard Arabic has its own set of overused strategic phrases. Watch for:

- عبارات الإلهام العامة (generic inspiration phrases) that could apply to any brand
- الاقتباسات الدينية (religious quotations) used decoratively rather than substantively
- وصف الجمهور بالمفرد الجماعي (describing the audience as a unified collective) when the actual audience is more divided

The test is the same in every language: read it aloud. If it sounds like every other brand, rewrite it.
